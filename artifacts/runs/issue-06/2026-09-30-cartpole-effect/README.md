目的：直接测量每个 CartPole 回合维持的步数。CartPole 每走一步获得 1 分，因此此处总奖励等于持续步数；达到 500 步时由环境时间上限截断。完整的逐回合步数、奖励和终止标志见 [output.json](output.json)。

| 0 | 98.1 | 96.0 | 79–126 | 0 |
| 4096 | 84.9 | 82.5 | 48–146 | 0 |
| 8192 | 91.1 | 83.5 | 51–146 | 0 |
| 16384 | 455.5 | 473.5 | 365–500 | 4 |
| 32768 | 161.3 | 157.0 | 147–194 | 0 |

本次固定种子和参数下，16,384 步检查点表现最好；继续训练后反而下降。这里记录的是一次运行轨迹，不能推出 PPO 总能提升或 16,384 步必然最优。先前的 32 步、两轮训练仅用于验证程序顺序，与本实验的效果评估是两个独立实验。
