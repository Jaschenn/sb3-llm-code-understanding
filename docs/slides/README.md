# 课堂汇报幻灯片

`index.html` 是单文件幻灯片，浏览器直接打开即可，无需构建。内容全部取自报告和证据文件，每页页脚写明对应的证据编号（`C-xx-xx`、`AI-xx-xx`）。

| 操作 | 按键 |
|---|---|
| 下一步 / 上一步 | → ↓ 空格 / ← ↑（每页内容逐条出现，出完才翻页） |
| 显示或隐藏演讲者备注 | N |
| 全屏 | F |
| 当前页内容全部显示 | A |
| 直接打开第 4 页，并显示全部内容 | `index.html?all#4` |

页面按 1920×1080 设计并整体缩放，投影比例不同时只会留边，不会改变排版。字体通过 Google Fonts 加载，离线时回退到系统字体，不影响版式。

打印或另存为 PDF：用浏览器打开 `index.html`，选择打印，纸张选“横向”、边距为“无”，勾选“背景图形”。打印时所有逐条内容会一并显示。

时间分配（约 10 分钟）：封面 0:20；问题与范围 1:00；方法 1:10；读到了什么 1:10；案例一 1:50；案例二 1:10；复核记录与维护侧 1:20；学到的 1:00；没能核验的 1:00。各页的讲稿提示在备注里（按 N）。
