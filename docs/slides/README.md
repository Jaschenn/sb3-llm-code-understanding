# 课堂汇报幻灯片

`index.html` 是浏览器直接打开的 HTML 幻灯片，无需构建。当前恢复原 13 页阅读版的内容、校对稿风格、类图、调用链与案例，在相关章节后新增 5 页真实 GitHub 截图，共 18 页。并未沿用以 T04 为主线的 12 页重排版。

| 操作 | 按键 |
|---|---|
| 下一页 / 上一页 | → ↓ 空格 / ← ↑ |
| 显示或隐藏本页讲稿 | N |
| 全屏 | F |
| 跳到指定页 | `index.html#4` |

每次翻页立即显示整页内容。原有 `?all` 链接兼容。页面按 1920×1080 整体缩放。打印时显示所有页面并隐藏进度条、备注与操作提示。
